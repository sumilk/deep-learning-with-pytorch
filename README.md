# Deep Learning with PyTorch

A gradual, visual, hands-on course: tensors and perceptrons → MLPs → CNNs → recurrent sequence models → attention → Transformers.

## Start here

Read the [lesson plan](LESSON_PLAN.md) for the proposed 56-notebook curriculum, practice problems, and teaching approach.

**Status:** Planning stage. No tutorial notebooks have been implemented yet. Notebook development will begin after review of the lesson plan.

## Learning approach

- Introduce the required math alongside the code; assume basic Python.
- Build intuition using diagrams, plots, small numerical examples, and experiments.
- Implement important components from scratch, then compare with PyTorch.
- Practice with implementation challenges, deliberate bugs, tricky datasets, and failure analysis.
- Keep core labs small enough for CPU execution using locally generated data; offer optional real-dataset extensions.
